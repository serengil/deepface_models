# Pre-Trained Models for DeepFace

Pre-trained weights in deepface were stored in Google Drive source but it has a daily download limit. Users can get **"Too many users have viewed or downloaded this file recently. Please try accessing the file again later"** often. That's why, pre-trained weights are going to be stored in this repo as a release.

The DeepFace repo itself is licensed under MIT - see [`LICENSE`](https://github.com/serengil/deepface_models/blob/main/LICENSE). However, the library wraps some face recognition models of external studies. Please check out [`license`](https://github.com/serengil/deepface#licence) section of DeepFace repo to find out reference studies. Licence types will be inherited if you are going to use those models.
